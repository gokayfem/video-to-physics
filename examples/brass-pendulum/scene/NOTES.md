## What was built
* `build.py` (+ `pnd_nodes.py`): deterministic builder. Reads `L_c` from `params/physics.json`
  (`L_c.value`, or `parameters.L_c_m.value`) and every other size as a ratio from `params/geometry.json`.
  * `PND_Stand`: `PND_StandControls` (hidden from render, display Bounds) carries the **PND Stand** GN modifier with all
    controls; `PND_Base`, `PND_Post`, `PND_Arm`, `PND_PostBolt` each run **PND Stand Part** (Object Info of the controls
    object → keep faces with `pnd_part` = 0/1/2/3 → Set Material). Edit the stand in one place.
  * `PND_Pivot`: `PND_Pin` (**PND Pin**: shaft from inside the arm, head shoulder, domed tip) and `PND_WireLoop`
    (**PND Wire Loop**: ring in the YZ plane whose lowest centreline point is P). Both static.
  * `PND_Swing` collection: empty `PND_Swing` at P, identity rest rotation, unparented; children `PND_Wire`
    (16-sided tube with ring centroids exactly at (0,0,0) and (0,0,−(L_c−r_b)), local) and `PND_Bob` (UV sphere 64×32,
    origin = bob centre at local (0,0,−L_c), top pole = wire bottom). Parent inverse = identity. Rigid children, so
    attachments cannot slide.
  * Hooks: `--look` imports `scene/look.py` and calls `apply_look(scene, params)` (params: root, L_c_m, dims_m,
    geometry, physics, object and material names). `--bake CSV` runs `solver/bake_blender.py` in-process via
    `runpy` with `--trajectory CSV --bob-object PND_Bob --report <out>.bake.json` (its code is not copied).
    Without `--look`: placeholder floor/light/world (`PND_EnvPlaceholder`). The camera `PND_CamGeomApprox` is the
    geometry role's approximate frame-0 camera, scaled by L_c; look.py may replace it.
  * Writes `<out>.build.json` (input hashes, dims, per-object evaluated-mesh sha256, transforms, lint, warnings) and
    `<out>.graph.json` (nodekit dump). Lint: 0 problems; node warnings: none.
* GN controls: see `GRAPH.md` and `CONTROLS.md` (generated by the skill's `graph_doc.py`; do not edit).
  Primary: Post Height, Arm Length, Base Width/Depth/Thickness, Base Edge Radius, Wood Edge Radius. Placement: Pivot
  Height, Arm End X, Arm Centre Z, arm/post sections, Base Left Margin, Base Centre Y, corner radii. The arm end face
  is the anchor (pin and pendulum never move); post and base follow. Nothing reads time.
* `check_rig.py`: reopens a .blend and checks the rig numerically (results below).
* `measure/`: `landmarks_f000.json`, `landmarks_f120.json` (hand readings + auto edge points), `fit_proportions.py`
  (joint fit), `edge_points.py`, `make_geometry_params.py` (writes params/geometry.json), `silhouette_iou.py`.
* Preview tools: `preview_render.py` (960×544 EEVEE; `--border` full-res crops; `--mask` silhouette), `make_visual.py`
  (labelled reference | current | previous | overlay), `preview.sh vNNN "caption" [prev.png]`, `sweep_controls.py`,
  `compare_builds.py`.

## How the proportions were measured
Frames 0 (t = 0 s) and 120 (t = 5 s), full resolution. 21 / 20 point landmarks read on 2×/4× nearest-neighbour zooms
with a 10 px grid (pivot = wire exit at the bottom of the loop; bob circle fitted to its silhouette; pin tip; arm-end
face corners; arm/post junction; post top and bottom corners; base corners), plus 30 / 31 automatically sampled
points on the base's back and left top edges (line constraints). A parametric box model (pivot at the origin, scale
L_c = 1) and one pinhole camera per frame (the clip zooms slightly: 2698 → 2749 px focal) were fitted jointly by
least squares: 145 observations, 33 parameters, rms 0.76 σ; edge lines 0.5–0.7 px rms. Every ratio, its σ (from the
fit covariance, never below the stated pixel σ), method and a `perspective_sensitive` flag are in
`params/geometry.json`. Bob radius / L_c = 0.0813 ± 0.003 (direct pixel ratio 0.0806 as a cross-check).
Details read by eye (pin and loop radii, wire diameter, edge radii, bolt) are marked `approximate`/`assumed`.
Contact-derived pin axis height 2·R_loop − r_w − r_pin = 0.0323 L_c agrees with the free fit 0.0326 ± 0.0025.

Key ratios (×L_c; mm at L_c = 0.3867 m): bob r 0.0813 (31.4), h_pivot 1.138 (440), bob-to-base clearance 0.057 (22),
post 0.175 × 0.145 × 1.276 high (68 × 56 × 493), arm 0.115 h × 0.082 d, visible 0.442 long (45 × 32 × 171),
base 1.299 × 0.644 × 0.172 (502 × 249 × 67), pin r 0.022 (8.5), head r 0.027, wire Ø 0.0035 (1.4).

## check_rig results (`out/check_rig.json`, final file)
* Euler convention: **`rotation_euler[1] = −θ`** (XYZ) gives bob = P + L_c(sin θ, 0, −cos θ); max error 3e-8 m. The
  other five axis/sign candidates fail.
* Over θ = −30…+30°: wire top to P ≤ 2.8e-11 m; wire bottom to bob surface ≤ 7.1e-8 m; wire bottom to bob top
  pole ≤ 9.0e-8 m; |bob − P| − L_c ≤ 2.3e-8 m; out-of-plane 0. All < 1e-6 m.
* Over ±20° (0.25° steps), measured-ratio bob (pre-CHANGELOG #2 build): min bob clearance to base 22.0 mm (at θ = 0), post 34.1 mm (θ = −20°), arm/bolt/pin/loop
  > 0.3 m; wire clearance to base 85 mm, post 76 mm, arm 23 mm. No intersections. PASS.
* Final file is baked (`--bake solver/out/trajectory.csv`, placeholder trajectory): bake_blender reports max angle
  error 5.2e-7 rad over frames+subframes, bob position error 2.1e-7 m. check_rig detaches the action only for its
  own poses (file not saved) and PASSES on it: bob radius 0.029745 m (physics.json), rig L_c − physics L_c = 0,
  min bob–base clearance 23.7 mm.

## Open issues
1. The pin axis lies in the swing plane (along X), so the loop cannot act as a hinge about the pin; the wire is modelled
   as leaving a static loop at P with a small kink (≤ amplitude). The reference is AI-generated; physically a loop on
   an X-axis pin would rock or flex. P is the wire exit point, as CONTRACT defines it.
2. The reference camera zooms slightly (focal +1.9 % from f0 to f120) — the preview camera is frame 0 only.
3. The bolt on the post's −X face needs ~0.085 L_c protrusion to show where the reference draws it; likely an
   inconsistency in the AI clip.
4. Base edge radii, wire/loop thickness and bolt are eye estimates. The wire loop reads thinner than in the reference.
5. No `scene/look.py` yet: the `--look` path is untested end-to-end.
