# Controls

The `PND Stand` modifier panel, generated by `scripts/graph_doc.py` from the built file. Defaults are the reference look. Colours are shown as sRGB.

## Primary

| Control | Default | Range | What it does |
|---|---|---|---|
| Post Height | 0.49 | 0.05 – 5 | Post top above the base top surface |
| Arm Length | 0.17 | 0.02 – 5 | Visible arm length from the post's +X face to the arm end face |
| Base Width | 0.5 | 0.05 – 5 | Base size along X (swing plane direction) |
| Base Depth | 0.23 | 0.05 – 5 | Base size along Y (towards / away from the camera) |
| Base Thickness | 0.065 | 0.005 – 1 | Base slab thickness |
| Base Edge Radius | 0.0085 | 0 – 0.2 | Rounding of the base's top edges |
| Wood Edge Radius | 0.0023 | 0 – 0.05 | Edge softening of the post and arm |
