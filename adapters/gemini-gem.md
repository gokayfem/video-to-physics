# Gemini (Gem)

1. Create a Gem and paste `adapters/universal-system-prompt.md` (the part below the line) into its instructions.
2. Add `skills/video-to-physics/SKILL.md` and `references/physics-routing.md`, `references/verification.md` as files.

For Gemini CLI, install the extension instead: `gemini extensions install https://github.com/gokayfem/video-to-physics`.
